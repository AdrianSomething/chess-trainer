# Custom icons

Enable custom icons in Settings. Place PNGs here and reopen the relevant menu (restart for existing windows). Recommended: 64 × 64 pixels, a light symbol on a transparent or black background. Monochrome menu symbols treat black as transparent and use the theme's foreground color. Missing files use built-in drawings.

Common names: generator.png, puzzles.png, custom-game.png, local-game.png, games.png, reload.png, settings.png, sound-on.png, sound-off.png, back.png, vision.png, puzzle-quick.png, puzzle-exploit.png.

Assessment symbols may use the existing assessment-sheet.png and category overrides; preserve its established layout when replacing it. Other keys include assessment-blunder, assessment-missed, assessment-mistake, assessment-best, assessment-good, endgame-queen, endgame-rook, endgame-bishops, endgame-bishop-knight, endgame-pawn and endgame-pawns.
