# UI color themes

Copy midnight.json or white.json to a new file with a unique id/name. The colors object maps original #RRGGBB colors to replacement colors, retaining transparency. Restart and select the theme in Settings. Standard - Dark has no replacements.

Useful original colors: background #1F2327, graph #1D2126, lists #2B3137, buttons #395B77, text #DCDCDC, hints #87CEFA, warning #FFA500, scrollbar track #20262C, thumb #5E6F7F and input arrows #9BA3AB.

branchNodes optionally defines unknown, seen, learned, due, later and excluded colors; append -opponent for opponent nodes. white.json is a complete light-theme example. Native input arrows, scrollbars and Windows 11 title bars use the shared palette. Light backgrounds use contrasting dark button text.

Board colors and silhouettes remain separate skins. Animation duration (0–200%) and marking settings are independent of the theme.
